# 部署说明

本项目是纯静态网站，部署时只需要将根目录中的以下四个文件放在同一级目录：

- `index.html`
- `styles.css`
- `app.js`
- `topics.js`

## 普通静态服务器

将四个文件上传到 Nginx、Apache、阿里云轻量应用服务器或其他静态托管平台的网站根目录，并把默认首页设置为 `index.html`。

Ubuntu 服务器可以使用仓库内的 `deploy/setup-ubuntu.sh` 完成首次部署。运行前先确认服务器来源可信，并在仓库中检查脚本内容：

```bash
curl -fsSL https://raw.githubusercontent.com/ZMWT-L/kaikou-youdiandongxi/main/deploy/setup-ubuntu.sh -o /tmp/setup-ubuntu.sh
sudo bash /tmp/setup-ubuntu.sh
```

Nginx 最小配置示例：

```nginx
server {
    listen 80;
    server_name example.com;
    root /var/www/site;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

正式使用时应为域名配置 HTTPS 证书，并开放服务器的 80 和 443 端口。

## GitHub Pages

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. Branch 选择 `main`，目录选择 `/(root)`。
4. 保存并等待 GitHub 完成发布。

如果继续使用现有的 `zmwt.online` 托管，不要在 GitHub Pages 中填写该自定义域名，以免与当前 DNS 配置冲突。
